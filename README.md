### Clinical Management System (GYNFEM)

billing, ultrasound reports all manual and error-prone. I built a full clinical

During crisis events, families searching for missing relatives have no reliable way

offline-tolerant design built for low-connectivity regions. Full technical
documentation (PRD, architecture, ERD, API spec) completed; build phase in progress.
